# KEMINTAS

KEMINTAS is my personal project for building small web tools and operating personal infrastructure.

I turn everyday inconveniences and repetitive tasks into simple web-based tools. Tools that can be safely shared are collected on kemintas.com and provided as small utilities that anyone can use.

I also incorporate AI-assisted coding into development, but the goal is not simply to generate something and stop there. I review the purpose, public exposure, maintainability, and operational rules, then refine each tool into something that can actually be used.

For public services, I focus not only on appearance and functionality, but also on page structure that clearly communicates the purpose of each tool, search engine metadata, link preview behavior, and an operation model that can be maintained over time.

I separate public services, private services, and development environments, and manage what can be public, what requires authentication, and what should not be exposed externally. I also maintain the surrounding operational foundation, including DNS, email authentication, access control, and monitoring, so the project can be operated continuously even at a small scale.

Some tools are published as open source projects on GitHub. Public code and the actual production environment are managed separately, and only information that is safe to share is organized and published.

KEMINTAS is not a finished large-scale service. It is a place where I take problems I find in my daily life and work, build small solutions, use them in practice, and improve them through ongoing operation.

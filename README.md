# KEMINTAS

KEMINTASは、個人で開発・運用しているWebツール群とインフラ運用プロジェクトです。

日常の小さな不便や、繰り返し発生する作業を、シンプルなWebツールとして形にしています。公開できるものは[kemintas.com](https://kemintas.com)に集約し、誰でも使える小さなユーティリティとして提供しています。

開発にはAIによるコーディング支援も取り入れていますが、生成されたコードをそのまま完成形とはせず、用途、公開範囲、保守性、セキュリティ、運用ルールを確認しながら整えています。

KEMINTASでは、Webアプリケーションの開発だけでなく、VPS、自宅サーバー、WireGuard、Docker、リバースプロキシ、DNS、監視、通知、バックアップまで含めて運用しています。公開サービス、非公開サービス、開発環境を分離し、小規模でも継続して安全に使える構成を目指しています。

一部のツールはGitHubでOSSとして公開しています。公開用コードと実運用環境は分離し、内部構成、認証情報、運用スクリプト、環境固有の設定は公開リポジトリに含めない方針です。

KEMINTASは、身近な課題を小さく作り、実際に使いながら改善し続けるための個人プロジェクトです。

---

KEMINTAS is a personal project where I develop and operate a collection of web tools and self-hosted infrastructure.

I build simple web tools to solve small everyday inconveniences and repetitive tasks. Tools that can be made public are collected on [kemintas.com](https://kemintas.com) and provided as small utilities that anyone can use.

I use AI-assisted coding as part of the development process, but I do not treat generated code as finished work. I review and refine it with attention to purpose, public exposure, maintainability, security, and operational rules.

KEMINTAS covers not only web application development, but also infrastructure operation, including VPS hosting, a home server, WireGuard, Docker, reverse proxies, DNS, monitoring, notifications, and backups. Public services, private services, and development environments are separated, with the goal of keeping the system small, secure, and continuously maintainable.

Some tools are published as open source on GitHub. Public repositories are separated from the production environment, and do not include internal architecture details, credentials, operational scripts, or environment-specific configurations.

KEMINTAS is a personal project for building small solutions to real problems, using them in practice, and improving them over time.

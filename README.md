# KEMINTAS

KEMINTAS is my personal project for building small web tools and operating personal infrastructure.

I turn everyday inconveniences and repetitive tasks into simple web-based tools. I use AI-assisted coding in development, but I focus on refining each tool with clear purpose, public exposure, maintainability, and operational rules.

For public services, I care not only about appearance and functionality, but also about clear page structure, search metadata, link previews, and long-term maintainability.

I separate public services, private services, and development environments, and maintain the surrounding operational foundation, including DNS, email authentication, access control, and monitoring.

Some tools are published as open source projects on GitHub. Public code and the actual production environment are managed separately, and only information that is safe to share is published.

KEMINTAS is not a finished large-scale service. It is a place where I build small solutions to problems I find in daily life and work, use them in practice, and improve them through ongoing operation.
